# ML module

This package contains the recommendation inference layer for the movie recommendation system.

## Structure

- `models/`: trained model artifacts (to be added later)
- `data/`: datasets (to be added later)
- `services/`: recommendation service implementations
- `mock/`: mock recommendation provider for local development
- `utils/`: preprocessing and helper utilities
- `config.py`: shared configuration values

## Usage

The backend should depend on the service layer, not on model files directly.
